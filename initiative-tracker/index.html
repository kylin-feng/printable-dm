What's inside

  • Initiative roster (22 slots) — initiative score, name, AC, HP max and a wide notes column, ordered top to bottom so you read the turn order like a script.
  • Round & turn strip — tick-boxes for rounds 1–20 plus a ‘delayed/held action’ marker column so nobody gets skipped twice.
  • Quick-reference sidebar — surprise rules, tie-breaking by Dexterity, and the readied-action trigger reminder, right where you write the order.

How to use it

Print one per fight (or laminate one and use dry-erase markers). Write every combatant in initiative order before the first turn — players first, then monsters, then lair actions if you use them. During play, work straight down the sheet and back to the top, ticking the round box each time initiative order wraps.

The AC column sits next to the name so you can answer “does a 17 hit the ogre?” without flipping to the stat block. Use the HP column as damage tally marks rather than numbers — it is faster at the table and arithmetic errors drop to zero. The notes column earns its width for concentration spells, marks from hunters, and “this one flees at half HP” reminders to future-you.

Printing tip: Print at 100% scale (“Actual size”, not “Fit”) so the ruling stays exactly 22 rows; margins are already sized for a three-hole punch.
