# Printable DM — Free Printable D&D 5e Tools

**Website: https://kylin-feng.github.io/printable-dm/**

Free, print-ready PDF tools for Dungeon Masters. No email wall, no watermark — download, print, play.

## The toolkit

| Tool | What it does |
|---|---|
| [Initiative Tracker](https://kylin-feng.github.io/printable-dm/initiative-tracker/) | 22-slot roster with AC/HP columns + round counter strip |
| [DM Screen Cheat Sheet](https://kylin-feng.github.io/printable-dm/dm-screen-cheat-sheet/) | 5 inserts: action economy, all 15 conditions, common DCs, dying rules |
| [Combat Tracker](https://kylin-feng.github.io/printable-dm/combat-tracker/) | 8 oversized combatant blocks with HP pips + concentration tracker |
| [Condition Cards](https://kylin-feng.github.io/printable-dm/condition-cards/) | 15 die-cut reference cards for your DM screen |
| [Session Notes Template](https://kylin-feng.github.io/printable-dm/session-notes-template/) | Two-page recap sheet: party status, NPCs, loot, hooks |

## Tech

Static site generated by `tools/build.mjs` (Node, zero dependencies); PDFs generated by `tools/make-pdfs.mjs` (pdfkit). Deployed on GitHub Pages. Summaries reference the D&D 5.1 SRD (CC-BY-4.0). Unofficial fan content, not affiliated with Wizards of the Coast.
